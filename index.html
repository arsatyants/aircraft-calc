Допущения модели
  • Винт: Ct(J)=Ct0·(1−(J/J0)²), Cp(J)=Cp0·(1−0.5·J/J0), J0≈0.85·шаг/диаметр.
  • Мотор: Kv, сопротивление обмотки, ток холостого хода; ESC КПД учтён; просадка батареи по внутреннему сопротивлению.
  • Крыло: площадь из заданной скорости сваливания; поляра CD=Cd0+CL²/(π·e·AR).
  • Крейсерская скорость — скорость максимальной дальности (макс. V/P) не ниже 1.3·Vсваливания.
  • Скорость отрыва = 1.2·Vсваливания; разбег — численное интегрирование при полном газе.
  • Это инженерная оценка (±15–25%); для точности подставляйте Ct/Cp своего винта из таблиц производителя.
